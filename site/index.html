Case files

Every case file comes with its own evidence grade

Each region is built from tiles that survive the false-discovery-rate (FDR) correction for testing thousands of tiles at once, then checked four more ways: does it hold in shorter time windows, do two definitions of “neighbour” agree it is a cluster, does an independent precipitation product (CHIRPS, via NASA FLDAS) show the same sign, and does independent research see it too. Each case file shows which checks pass and which do not.
